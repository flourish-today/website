Privacy and security

Beeswax collects and shares no personal data. It has no telemetry, one permission, and no network access. It has reproducible builds so you can verify the source code is what runs on your device.

Device management APIs used

Beeswax uses its Device Owner capability responsibly by only using these few Device Management APIs it needs to function:

Blocks factory reset from SettingsDevicePolicyManager.addUserRestriction and clearUserRestriction with DISALLOW_FACTORY_RESETWhen you turn Block factory reset on or off
Locks private DNSDevicePolicyManager.addUserRestriction and clearUserRestriction with DISALLOW_CONFIG_PRIVATE_DNSWhen you turn Lock private DNS on or off
Blocks and allows appsDevicePolicyManager.setApplicationHiddenBlocks the apps switched off in the list (browsers by default) when you lock, an app installed while locked, and an app you switch off in the list. Blocks them again whenever Guard starts, for example after a restart. Allows an app when you switch it on in the list, and every app when you tap Deactivate
Stops a blocked built-in app from being uninstalled, so Settings' "Uninstall updates" can't bring back an unblocked copyDevicePolicyManager.setUninstallBlockedWhen a built-in app is blocked. Lifted when you allow it, and for every app when you tap Deactivate

APIs used to read the phone

These only read, and change nothing. Before you lock, Beeswax uses only these to show its list, and it applies your switches only when you tap Lock.

What it doesAndroid APIWhen
Lists the apps on your phonePackageManager.getInstalledPackages, PackageManager.getPackageInfoWhen Beeswax shows its list, when you lock, when you block or allow an app, when an app is installed while locked, when Guard starts, and when you tap Deactivate
Finds browsers (apps that call themselves a browser, and apps that can open any web link) and apps with a home screen icon, so built-in ones are listed tooPackageManager.queryIntentActivitiesWhen Beeswax shows its list, and when you lock
Shows each app's name and iconApplicationInfo.loadLabel, ApplicationInfo.loadIconWhen Beeswax shows its list
Finds the keyboards you've turned on, so they're never listed or blockedInputMethodManager.getEnabledInputMethodListWhen Beeswax shows its list, when you lock, when you block an app, when a blocked app is installed or updated while locked, and when Guard starts
Finds Settings and the built-in phone, messaging and home screen apps in use, so they're never listed or blockedTelecomManager.getDefaultDialerPackage, Telephony.Sms.getDefaultSmsPackage, PackageManager.resolveActivity, PackageManager.queryIntentActivitiesWhen Beeswax shows its list, when you lock, when you block an app, when a blocked app is installed or updated while locked, and when Guard starts
Shows which apps are blocked, and finds every blocked app to allow it againDevicePolicyManager.isApplicationHiddenWhen Beeswax shows its list while locked, and when you tap Deactivate
Shows More settings' switches as Android has themDevicePolicyManager.getUserRestrictionsWhen More settings shows
Reads the private DNS set in Settings, so Lock private DNS can show it and refuse when none is setDevicePolicyManager.getGlobalPrivateDnsMode, DevicePolicyManager.getGlobalPrivateDnsHostWhen More settings shows
Finds every app whose uninstall Beeswax blocked, to lift itDevicePolicyManager.isUninstallBlockedWhen you tap Deactivate
Checks for other users, which Beeswax can't lock withDevicePolicyManager.getSecondaryUsersWhen you tap Lock
Checks that Beeswax is the device ownerDevicePolicyManager.isDeviceOwnerAppWhenever Beeswax's screen opens or changes

Risks to using Beeswax

  • Beeswax is a device-owner app, which gives it powers far beyond a normal app. Beeswax uses only the few listed above, but a future update signed with the same key could, for example, give Beeswax the ability to wipe your device.
  • If the lock code is lost while Beeswax is locked, the only way to unblock apps or allow new apps is a factory reset.
  • By using Beeswax, you're using Android in a non-standard way. Beeswax blocks browsers by default, including the built-in browser (Vanadium on GrapheneOS). GrapheneOS recognizes device owners as the standard way to manage devices, and ADB is currently the only way to set one up. However, GrapheneOS advises against apps that use these APIs to "disallow a bunch of functionality." [1]

Reproducible builds

This confirms the released APK was built from the public source code. Your build will match the release in every file; only the signature differs. Being open source with reproducible builds doesn't mean a third party has checked that the code is safe or that the builds match.

You need:

  • JDK 21, for example Temurin 21. If you have more than one Java installed, set JAVA_HOME to the Java 21 folder. Check that java -version shows 21.
  • Gradle 9.5.1, unzipped, with its bin folder on your PATH so the gradle command works. Package managers usually install a newer version, which won't match.
  • The Android SDK with platform 37.0 and build-tools 37.0.0, from Android Studio or Google's command-line tools. Set ANDROID_HOME to the SDK folder. With the command-line tools, install the parts with sdkmanager --sdk_root="$ANDROID_HOME" "platforms;android-37.0" "build-tools;37.0.0".

  1. Get the source for the release and build it:

    git clone https://github.com/flourish-today/beeswax.git
cd beeswax
git checkout v1.01
gradle --no-daemon :app:assembleRelease -Pandroid.aapt2FromMavenOverride="$ANDROID_HOME/build-tools/37.0.0/aapt2"

  2. Download Beeswax-1.01.apk from the v1.01 release into the beeswax folder.

  3. Unpack both APKs and compare them:

    mkdir rel mine
unzip -q Beeswax-1.01.apk -d rel
unzip -q app/build/outputs/apk/release/app-release-unsigned.apk -d mine
diff -rq rel mine && echo MATCH

If it prints MATCH, the release contains exactly what you built.

sha256sum app/build/outputs/apk/release/app-release-unsigned.apk

Please consider sharing the result in an issue no matter what result you got.
